<h2 id="sec1">§1 数据类型与变量</h2>

> 你的作答区；结构是小c整理的，可随时在下面加例子。

### 1.1 基本类型（8 种）

| 类型 | 字节数 | 默认值 | 数据范围 / 说明 |
| --- | --- | --- | --- |
| `boolean` | （不必死记字节） | `false` | `false` / `true` |
| `byte` | 1 | `0` | |
| `short` | 2 | `0` | −32768～32767 |
| `char` | 2 | `'\u0000'` | |
| `int` | 4 | `0` | 约 −21 亿～21 亿 |
| `long` | 8 | `0` | |
| `float` | 4 | `0.0f` | |
| `double` | 8 | `0.0` | |

### 1.2 包装类型

- **装箱**：基本 → 包装 · 例：`Integer i = 10;`
- **拆箱**：包装 → 基本 · 例：`int x = i;`

### 1.3 `char` 与 `String`

- `char` 单个字符，用单引号：`char c = 'a';`（基本类型不能 `new`）
- `String` 多个字符，用双引号：`String s = new String("hello 小c~");`

### 1.4 字面量

字面量是在源码直接写出来的常量，编译器一看就知道类型。

| 写法 | 类型 |
| --- | --- |
| `10` | `int` |
| `10L` | `long`（Java 没有 `long long`） |
| `10.0` | `double` |
| `'A'` | `char` |
| `"A"` | `String` |

### 1.5 强制转换

```java
int a = 10;
double b = (double)a;
```

类似这种，`string`（`"234"`）也可转成 `int`，但要用 **`Integer.parseInt("234")`**；`"asdf"` 会报错。  
`double`（3.14）转 `int` 会丢小数。

### 1.6 `final`

一旦赋值不能改成指向别的值；可变对象里仍可改内容（如 `StringBuilder` + `append`），但不能重新 `new` 赋给该引用。

### 1.7 标识符与命名

- 方法名、变量名：小驼峰（如 `helloXiaoC`）。
- **类名**：大驼峰。
- **包名**：全小写（见 [§4 末尾 · 命名约定](#sec4-naming)）。

### 1.8 `var`

根据初始值推断类型，类似 C++11 的 `auto`。**Java 10 起**可用。

<h2 id="sec2">§2 循环与分支</h2>

### 2.1 `if` / `else`

从上往下执行；有一层符合则执行对应分支并**结束整条分支结构**。

### 2.2 `switch` 与 `break`（贯穿）

忘了写 `break` 会一路执行下面的 `case`，即 **fall-through（贯穿）**。  
可用高速公路出口类比：某出口没有 `break` 就会继续往下。

### 2.3 `switch` 表达式（`->`，JDK 14+）

```java
switch(op) {
    case 1 -> func1();
    case 2 -> func2();
    case 3 -> func3();
    default -> func4();
}
```

省去手写 `break`，代码更清晰。

### 2.4 `while` / `do-while`

- **`while`**：先判断条件，再进循环体。
- **`do-while`**：先执行循环体，再判断（至少执行一次）。

### 2.5 `for(a; b; c)`

- **a**：初始化（一次）
- **b**：条件为真才继续
- **c**：每轮循环体执行完后的步进

**顺序**：`a` → 判 `b`（真）→ **循环体** → `c` → 判 `b` → … → 判 `b`（假）→ 退出。

### 2.6 增强 `for`

冒号右侧须为**数组**或 **`Iterable`**（如 `ArrayList`、`HashSet`）。  
例：`for (char c : str.toCharArray()) { }`  

适合遍历；要下标 / 第 `i` 个用普通 `for`。

### 2.7 `break` / `continue`

- **`break`**：跳出包住它的那一层循环（或 `switch`）。
- **`continue`**：跳过本轮剩余语句，进入**同一层**下一轮。

### 2.8 `while(true)` 如何退出

须有业务条件成立时用 **`return`** 或 **`break`** 退出。

<h2 id="sec3">§3 方法</h2>

### 3.1 返回值、方法名、参数列表

- **返回值类型**：`void` 无返回值，或 `String`、`int` 等由调用方接收。
- **方法名**：调用入口。
- **参数列表**：调用时传入的数据。

### 3.2 `return`

有返回值：返回 `return` 后面的值。  
`void`：结束方法；也可 **`return;`** 提前结束。

### 3.3 形参与实参 · Java 只有值传递

- **形参**：定义里括号中的名字，如 `void swap(int a, int b)` 的 `a`、`b`。
- **实参**：调用时传入的值，如 `swap(1, 2)` 的 `1`、`2`。

**Java 只有值传递**：基本类型传值的拷贝；引用类型传**引用的拷贝**（改对象内容外面可见；若形参改为指向新对象，外面原引用不变）。

### 3.4 方法重载

同一方法名，**参数个数或类型**不同；与参数名、返回值无关。**仅靠返回值不同不能重载。**

### 3.5 可变参数 `int... nums`

调用时可传任意个数；定义时**可变参数须在最后**。  
方法体内 **`nums` 即 `int[]`**，不是 `ArrayList`。

### 3.6 递归

要有**终止条件**，且每次调用应朝终止方向前进。

### 3.7 阶乘示例

```java
public static int fact(int n) {
    if (n <= 1) return 1;
    return fact(n - 1) * n;
}
```

调用示例：`int res = fact(5);`，终止条件即 `if (n <= 1)`。

### 3.8 `main` 入口

`public static void main(String[] args)`

| 关键字 | 含义 |
| --- | --- |
| `public` | 访问权限 |
| `static` | 静态方法 |
| `void` | 无返回值 |
| `main` | 程序入口方法名 |
| `String[] args` | 命令行参数，如 `java MyApp a b` → `args[0]` 为 `"a"` |

<h2 id="sec4">§4 补充：运算符 · 数组 · String · null · 作用域 · 注释与运行</h2>

> 查漏用结构；可继续在每一小节下加自己的例子。面向对象篇另开章节再接。

### 4.A 运算符与表达式

- **算术**：`+ - * / %`（整数除法会截断，如 `5 / 2` → `2`）。
- **自增自减**：`i++`（先用旧值再加 1）、`++i`（先加 1 再用）。
- **比较**：`== != < > <= >=`；引用类型用 `==` 比的是引用身份，字符串内容多用 `equals`（见 4.C）。
- **逻辑**：`&& || !`；**短路**：`a && b` 若 `a` 假则不计算 `b`。
- **赋值**：`= += -=` 等。
- **三元**：`条件 ? 值1 : 值2`。

### 4.B 数组

- **创建**：`int[] a = new int[3];`、`int[] b = {1, 2, 3};`
- **下标**：从 **0** 开始；**`a.length`**（无括号）。
- **越界**：`ArrayIndexOutOfBoundsException`。
- **二维（了解）**：`int[][] m = new int[2][3];`，`m.length`、`m[i].length`。

### 4.C `String` 补充

- **不可变**；大量拼接用 **`StringBuilder`**。
- **内容比较**：`s1.equals(s2)`；防 `null` 可写 `"abc".equals(s)`。
- **遍历字符**：`for (char c : s.toCharArray())`。

### 4.D `null` 与 NPE

引用可为 **`null`**；对 `null` 调方法会 **`NullPointerException`**，调用前常判 `if (s != null)`。

### 4.E 作用域 `{}`

在大括号内声明的变量只在该块内有效。

### 4.F 注释与编译运行

- **`//`** 单行 · **`/* */`** 多行 · **`/** */`** 文档注释。
- **`javac Hello.java`** → `Hello.class`；**`java Hello`**（不要带 `.class`）。

<h3 id="sec4-naming">4.G 命名约定</h3>

- **类名**：大驼峰 · **方法/变量**：小驼峰 · **包名**：全小写，如 `com.example.demo`。
